Sadya-Fi 🍽️🎉
==============

Bringing technology and tradition together, Sadya-Fi is a Next.js web application designed to streamline ticketing for the traditional Onam Sadhya event. Built with modern technologies such as Next.js, Firebase for the backend, and shadcn for the UI, Sadya-Fi makes organizing cultural events simpler, faster, and more efficient.

Features 🚀
-----------

### User Registration

-   Students can register for the Onam event seamlessly.
-   The registration process includes simple forms and validation to ensure accurate data entry.

### QR Code Generation

-   Unique QR codes are generated for each user upon successful registration.
-   These codes serve as tickets and are linked to individual user profiles for easy verification.

### Admin Approval

-   Admins can approve or reject students based on their payment status.
-   The approval process ensures that only confirmed participants are allowed to attend the event.

### QR Code Scanning

-   Easily verify attendees on the event day by scanning their QR codes with a mobile device.
-   Streamlined check-in process to avoid long lines and delays.

### Real-time Database

-   Firebase integration ensures instant updates across the platform, including registration status and event-related changes.
-   Real-time synchronization between users and admins for smooth event operations.

### Interactive Event Schedule

-   Displays the event's timeline to keep participants informed about various activities, timings, and schedules.
-   Allows admins to update the schedule dynamically if any changes occur.

Tech Stack 💻
-------------

-   **Frontend**: Next.js
-   **Backend & Database**: Firebase
-   **UI Library**: shadcn
-   **Authentication**: Firebase Authentication (Email/Password)
-   **QR Code Generation**: qrcode.react
-   **Deployment**: Vercel

Additional Features & Insights 🌟
---------------------------------

### Real-Time Event Management

-   **Instant Updates**: Changes to the event schedule or registration status are reflected immediately for all users.
-   **Notification System**: Admins can send out event notifications or updates to all registered participants to keep them informed.

### Scalable and Modular Design

-   Built with scalability in mind to accommodate both small and large-scale events.
-   The modular design allows for easy future feature additions or integration with other services.

### User-Friendly Interface

-   Designed with accessibility and ease of use in mind, ensuring both participants and admins can interact with the platform effortlessly.
-   Responsive design that works seamlessly on both desktop and mobile devices, making event management portable.

### Firebase Authentication

-   Secure user authentication is handled by Firebase Authentication, with options for email and password-based login, providing a safe and smooth experience for users.

### Admin Dashboard

-   Admins have access to a detailed dashboard that provides an overview of registrations, approvals, and overall event status.
-   Tools to manage QR code scans, approve or reject students, and update event details are included in the admin panel.
